# Whykey defect register

This register tracks concrete, reproducible behavior gaps and regressions
separately from the capability contract in [`support-matrix.json`](support-matrix.json)
and from accepted coverage limits. An item stays in the open table until its
behavior is fixed and a regression test covers it. Where the behavior depends
on a real program, the regression evidence includes a [lab](lab/README.md)
scenario that runs that program. A planned capability is not automatically a
defect; it belongs in the support matrix unless it contradicts a documented
guarantee.

more than the current evidence supports.
